# 雷區測繪（踩地雷）

單一 HTML 檔的踩地雷遊戲，不需要安裝或建置。用瀏覽器開啟 `index.html` 就能玩。

## 功能

- 三種難度：初級 9×9（10 雷）、中級 16×16（40 雷）、高級 16×30（99 雷）
- 第一下一定安全：點開的格子與周圍 8 格不放雷
- 插旗：電腦按右鍵；手機長按，或切換「插旗模式」
- 快速翻開：點已翻開的數字，周圍旗子數相同時翻開其餘格子
- 鍵盤：方向鍵移動、Enter 翻開、F 插旗
- 各難度最佳時間存在瀏覽器的 localStorage（只在本機）
- 支援淺色／深色主題

## 外部資源

字型從 Google Fonts 載入；離線時會改用系統字型，遊戲仍可玩。
